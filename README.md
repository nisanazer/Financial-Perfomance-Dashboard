# Financial Performance Dashboard

## 1. Project Overview

The Financial Performance Dashboard is an interactive Power BI project designed to analyze business financial performance. It provides insights into sales, profit, units sold, product performance, country-wise sales, segment-wise sales, and monthly sales trends.

## 2. Project Objective

The main objectives of this project are:

- To analyze overall sales and profit performance.
- To compare sales across different products and countries.
- To understand sales distribution across business segments.
- To identify monthly sales trends.
- To provide an interactive dashboard for exploring financial data.

## 3. Tools Used

- **Microsoft Power BI Desktop** – Data visualization and dashboard development.
- **Power Query** – Data import and preprocessing.
- **DAX** – Creating calculated measures and KPIs.

## 4. Dataset Information

The dataset contains financial information with the following columns:

- Segment
- Country
- Product
- Discount Band
- Units Sold
- Manufacturing Price
- Sale Price
- Gross Sales
- Discounts
- Sales
- COGS
- Profit
- Date
- Month Number
- Month Name
- Year

## 5. Data Preprocessing

The dataset was imported into Power BI and checked before creating the dashboard.

The following checks were performed:

- Checked column quality.
- Verified valid values.
- Checked for errors and empty values.
- Applied the data changes in Power BI.

The column quality check showed 100% valid values, 0% errors, and 0% empty values.

## 6. Key Performance Indicators (KPIs)

The dashboard includes four main KPI cards:

| KPI | Value |
|---|---:|
| Total Sales | 118.73M |
| Total Profit | 16.89M |
| Total Units Sold | 1.13M |
| Profit Margin | 14.23% |

A Sales vs Target gauge was also created to compare actual sales against a target of 120M.

Actual sales reached approximately 118.73M, which is close to the illustrative target.

## 7. Dashboard Visualizations

The dashboard includes the following visualizations:

1. **Sales vs Target – Gauge Chart:** Compares actual sales with the target.
2. **Sales by Segment – Donut Chart:** Shows sales distribution across business segments.
3. **Sales by Product – Column Chart:** Compares sales across different products.
4. **Sales by Country – Bar Chart:** Compares sales performance across countries.
5. **Monthly Sales Trend – Line Chart:** Displays changes in sales throughout the year.
6. **KPI Cards:** Display total sales, total profit, total units sold, and profit margin.

## 8. Key Business Insights

Based on the dashboard:

- Total sales reached approximately 118.73M.
- Total profit was approximately 16.89M.
- The overall profit margin was 14.23%.
- Total units sold were approximately 1.13M.
- Paseo was the highest-selling product, with approximately 33M in sales.
- The United States recorded the highest country-wise sales at approximately 25.0M.
- Canada followed closely with approximately 24.9M in sales.
- October recorded the highest monthly sales, at approximately 22M.
- March, May, and August recorded comparatively lower monthly sales, at approximately 6M each.

## 9. Interactive Features

The dashboard includes interactive slicers for:

- Country
- Product
- Segment
- Month Name
- Year

Two bookmark-based buttons were also added:

- **Overall View:** Displays the overall dashboard view.
- **Canada View:** Displays the dashboard filtered for Canada.

These features allow users to explore the data interactively.

## 10. Conclusion

The Financial Performance Dashboard provides a clear overview of business performance through interactive visualizations and key performance indicators.

It helps users understand sales trends, compare product and country performance, analyze profitability, and explore financial data more effectively.

This project demonstrates practical skills in data preprocessing, DAX measures, data visualization, and interactive dashboard development using Microsoft Power BI.
